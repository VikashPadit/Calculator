#  Calculator

A simple calculator application built using **Java** and **Spring Boot**. The application performs the four basic arithmetic operations on two user-provided numbers.

##  Features

- ➕ **Addition** – Adds two numbers.
- ➖ **Subtraction** – Subtracts the second number from the first.
- ✖️ **Multiplication** – Multiplies two numbers.
- ➗ **Division** – Divides the first number by the second.
